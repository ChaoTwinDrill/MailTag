# MailTag

## Como executar

1. Clone o repositório:

   ```bash
   git clone https://github.com/ChaoTwinDrill/MailTag.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd MailTag
   ```

3. Instale as dependências:

   ```bash
   npm install
   ```

4. Execute o aplicativo:

   ```bash
   npm run tauri dev
   ```
